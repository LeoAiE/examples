================================================================================
 AI AGENT PLATFORM - AIR-GAP TRANSFER INSTRUCTIONS
================================================================================

 This document tells you exactly how to set up the platform on a new machine
 from the text files in this folder. Follow each step in order.

================================================================================
 WHAT'S IN THIS FOLDER (ready_to_push/)
================================================================================

 00_SETUP_SCRIPT.py          - Python script that creates all folders & init files
 01_FRONTEND.txt             - Contains: frontend/index.html (the entire web UI)
 02_AGENTS.txt               - Contains: 23 Python files from agents/ folder
 03_CORE_BACKEND.txt         - Contains: config.py, llm_provider.py, main.py, api_server.py
 04_TOOLS.txt                - Contains: 33 Python files from tools/ folder
 05_DATABASES.txt            - Contains: 15 text databases, voter.csv, JSON presets, create_voter_db.py
 SETUP_INSTRUCTIONS.txt      - This file (you're reading it)


================================================================================
 STEP 1: RUN THE SETUP SCRIPT
================================================================================

 On the target machine, open a terminal and run:

    python 00_SETUP_SCRIPT.py

 Or to install to a specific path:

    python 00_SETUP_SCRIPT.py /path/to/install

 This creates the entire folder tree, all __init__.py files, .env template,
 requirements.txt, and main.py.


================================================================================
 STEP 2: INSTALL PYTHON DEPENDENCIES
================================================================================

    cd ai-agent-platform/V2/backend
    pip install -r requirements.txt

 Required packages:
   - openai>=1.51.0          (LLM API client)
   - anthropic>=0.39.0       (Claude API client)
   - google-generativeai>=0.8.0  (Gemini API, optional)
   - fastapi>=0.104.0        (Web framework)
   - uvicorn>=0.24.0         (ASGI server)
   - python-dotenv>=1.0.0    (Env file loader)
   - pydantic>=2.5.0         (Data validation)

 Python 3.10+ required. No other system dependencies.


================================================================================
 STEP 3: CONFIGURE .env FILE
================================================================================

 Edit:  V2/backend/.env

 FOR AIR-GAPPED SYSTEMS (local LLM):
   LLM_BASE_URL=http://your-local-llm:8080/v1
   LLM_API_KEY=dummy-key
   LLM_MODEL=your-model-name
   LLM_PROVIDER=openai

 FOR CLOUD (internet access):
   OPENAI_API_KEY=sk-your-key
   ANTHROPIC_API_KEY=sk-ant-your-key
   DEFAULT_LLM_PROVIDER=openai
   DEFAULT_MODEL=gpt-4o-mini

================================================================================
 DATABASE FORMAT GUIDE (for generating your own data)
================================================================================

 All .txt databases use the SAME format:
   - Records separated by blank lines
   - Each record starts with a UNIQUE ID (e.g., TRAVEL_RECORD_001)
   - Fields are "Key: Value" format, one per line
   - Some fields span multiple lines (indented with spaces)

 EXAMPLE RECORD FORMAT (travel_db.txt):
    TRAVEL_RECORD_001
    Name: John Smith
    Arabic Name: N/A
    Passport: US-X1234567
    Phone: +1-555-0123
    Email: john.smith@email.com
    Flight: NYC (JFK) -> London (LHR)
    Date: 2024-01-15
    Booking Ref: BR-2024-0042
    Co-Travelers: Maria Garcia (+1-555-0124)
    Notes: Business class, window seat

 To generate new data: Give an AI assistant the sample records from
 05_DATABASES.txt and ask it to generate more in the same format.
 Just dump the generated text into the .txt files.

 The voter.csv is standard CSV with headers:
    first_name,father_name,grandfather_name,family_name,voter_id,
    national_id,city,mother_name,phone,date_of_birth,gender,registration_date

 The .json files (leos.json, targeting_workflows.json) are JSON objects.
 They store saved workflow definitions. Can start empty: {}

 The .db files (results_store.db, target_store.db) are SQLite databases
 that are AUTO-CREATED on first run. Do NOT copy these - they regenerate.


================================================================================
 IMPORTANT NOTES
================================================================================

 1. The .db files (results_store.db, target_store.db, voter_registration.db)
    are AUTO-GENERATED. Do NOT include them in transfer. They create themselves.

 2. The platform works with ANY OpenAI-compatible API endpoint. For air-gapped
    deployments, point LLM_BASE_URL to your local LLM server (vLLM, Ollama,
    text-generation-inference, etc.)

 3. All 16 agents share the same architecture. To add a new agent:
    - Create a new agent file inheriting BaseAgent
    - Create its database .txt file
    - Add the DB path to config.py
    - Register it in orchestrator.py (6 locations)
    - Add agent info to api_server.py
    - Add nav item + chat panel to index.html

 4. The frontend is a SINGLE HTML file. No build step, no Node.js, no npm.
    It uses vanilla JavaScript, CSS variables, and fetch() for API calls.

 5. To change the API port from 8000, edit main.py and update API_BASE_URL
    in index.html (line ~565: const API_BASE_URL = 'http://localhost:8000')
